# Assets · Apresentação Líderes Outubro 2026

Arquivos usados pela apresentação animada `#261104_Apresentacao_Lideres_Outubro.html`.

- `img/` e `fonts/` são servidos pelo jsDelivr:
  `https://cdn.jsdelivr.net/gh/marketingnovavidati-del/assets-outubro-lideres@main/<pasta>/<arquivo>`
- `video/` é servido pelo raw do GitHub (os vídeos passam do limite de 20 MB do jsDelivr):
  `https://raw.githubusercontent.com/marketingnovavidati-del/assets-outubro-lideres/main/video/<arquivo>`

Para trocar um arquivo, suba o novo com **o mesmo nome**; o HTML não precisa mudar
(no jsDelivr pode levar até 12 h para atualizar o cache, ou troque o `?v=` no HTML).

| Pasta | Conteúdo |
|---|---|
| `fonts/` | Poppins e Inter (400/500) + `fonts.css` |
| `img/` | logos, marca, ícones dos slides e foto do slide final |
| `video/` | `opera-sms.mp4` (slide 06) e `congonhas.mp4` (slide 07) |
